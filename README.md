# 🎯 Number Guessing Game

A simple and fun browser-based number guessing game built with vanilla JavaScript.

## 📖 Description

Test your guessing skills! The computer picks a random number between 1 and 100, and your goal is to guess it with as few attempts as possible. After each guess, you'll receive hints telling you if your guess was too high or too low.

## 🎮 How to Play

1. Open `index.html` in your web browser
2. A prompt will appear asking you to guess a number between 1-100
3. Enter your guess and click OK
4. You'll receive feedback:
   - **"Too low!"** - Your guess is below the secret number
   - **"Too high!"** - Your guess is above the secret number
   - **"Congratulations!"** - You found the correct number!
5. Keep guessing until you find the number
6. Try to minimize your attempts!
